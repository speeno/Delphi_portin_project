## 1. 「기간별재고원장」 — 웹에서는 「재고현황」입니다

### 여쭙는 것

레거시 원장관리의 「기간별재고원장」을 복원해 달라고 하셨습니다. 이 기능은 **웹의 「재고현황」**이
이미 하고 있습니다. 이름을 어떻게 할지 정해 주세요.

### 확인한 사실

레거시 화면(위러브솔루션 빌드)과 웹 화면의 **열 구성이 같습니다.**


| 구분  | 열                                                    |
| --- | ---------------------------------------------------- |
| 레거시 | 전재고 · 입고 · 반입 · 출고 · 증정 · 반품 · 폐기 · 변경 · 현재고 · 재고(반) |
| 웹   | 같음 (10열 전부)                                          |


조회 조건도 같습니다. 거래일자 기간, 도서명, 분류명.

9월 12일 경리부에서 알려주신 수치 불일치 두 건을 고친 뒤, 2025년 전 기간으로 대조하니 **10열이
모두 일치**했습니다.


| 전재고     | 입고      | 출고      | 증정    | 반품      | 폐기     | 변경     | 현재고     | 도서 수   |
| ------- | ------- | ------- | ----- | ------- | ------ | ------ | ------- | ------ |
| 506,368 | 127,404 | 144,581 | 7,439 | −25,478 | −1,087 | −9,369 | 496,772 | 2,971종 |


즉 화면이 없어서 못 보신 게 아니라, **이름이 달라서 못 찾으신 것**입니다.

### 선택지

- **(가) 지금 이름 유지** — 「재고현황」. 웹의 다른 현황 화면(출고현황·입고현황·반품현황)과 규칙이 맞습니다.
- **(나) 레거시 이름으로 변경** — 「기간별재고원장」.
- **(다) 병기** — 「재고현황(기간별재고원장)」.

**권고: (다) 병기.** 레거시 호칭이 몸에 익으신 분과 새로 쓰시는 분 모두 찾을 수 있습니다.
메뉴에서만 병기하고 화면 안쪽은 「재고현황」으로 두면 화면이 지저분해지지 않습니다.

## 2. 「거래처원장총괄」 — 새 화면 대신 기존 화면을 넓히는 안을 권합니다

### 여쭙는 것

레거시 「거래처원장총괄」은 웹에 없습니다. 새 화면을 만들지, 이미 있는 「통합 거래처원장」을
넓힐지 정해 주세요.

### 확인한 사실

레거시 화면을 열어 두 화면을 비교했습니다.


| 구분     | 거래처원장총괄 (레거시)                                  | 통합 거래처원장 (웹)        |
| ------ | ---------------------------------------------- | ------------------ |
| 상단     | 거래처별 — 출고수량·출고금액·반품수량·반품금액·증정수량·수금액·미수금        | 거래처별 — 거의 같은 구성    |
| 하단     | **년월별** 추이 — 위 항목 + 판매금액                       | **전표별** 상세         |
| 조회 조건  | 거래일자 기간 · 거래처명 · 본사출고제외                        | 거래일자 기간 · 거래처      |


**상단은 이미 같습니다.** 다른 것은 하단 한 곳뿐입니다. 레거시는 년월별 추이를 보여주고, 웹은
전표 하나하나를 보여줍니다.

계산에 쓰는 자료도 같습니다. 레거시 거래처원장총괄이 읽는 4개 테이블은 저희가 9월 12일
기간별미수원장을 만들면서 **이미 검증을 마친 것과 동일**합니다. 새로 계산식을 만들 필요가 없습니다.

### 선택지

- **(가) 새 화면을 만든다** — 레거시와 똑같이. 상단이 거의 같은 화면이 두 개가 됩니다.
- **(나) 통합 거래처원장 하단에 「년월별」 보기를 더한다** — 전표별 / 년월별을 버튼으로 전환.
  판매금액 열도 같이 넣습니다.

**권고: (나).** 상단이 같은 화면을 두 개 두면 어느 쪽을 봐야 하는지 헷갈립니다. 하단 전환
하나만 더하면 레거시로 하시던 일이 그대로 됩니다. 다만 두 화면을 따로 쓰시던 습관이 있으시면
(가)로 진행하겠습니다.

### 레거시에 있는데 웹에 아직 없는 화면

## 3. 「도서별수불원장」을 어느 메뉴에 둘지

### 여쭙는 것

9월 12일에 「원장변경만 빼고 재고 관련 메뉴를 재고관리 그룹으로 옮겨 달라」고 하셨습니다.
도서별수불원장은 재고 움직임을 보는 화면이지만 이름이 「원장」이라 **원장관리에 그대로 두었습니다.**
옮길지 정해 주세요.

### 확인한 사실

레거시는 도서별수불원장을 **원장관리**에, 거래처거래원장 바로 다음 자리에 두고 있습니다.
참고로 레거시에서 원장변경·재고변경은 원장관리가 아니라 **자료관리** 메뉴에 있습니다.

현재 웹 메뉴는 이렇습니다.


| 재고관리 | 원장관리       |
| ---- | ---------- |
| 재고현황 | 거래처거래원장    |
| 재고금액 | 도서별수불원장 ← |
| 재고변경 | 기간별미수원장    |
|      | 도서별원장총괄    |
|      | 원장변경       |


**권고: 원장관리 유지.** 레거시와 같은 자리이고, 이 화면은 거래처별 수불을 보는 성격이라 재고 현황
3종과 쓰임이 다릅니다. 다만 재고 업무 중에 자주 여신다면 옮기겠습니다.

## 4. 새 「도서구분」 — 값 목록과 기존 칸의 새 이름

### 여쭙는 것

9월 11일 도서코드 요청서 회신에서 이렇게 말씀하셨습니다.

> 도서구분이 창고, 본사로 나눠진다고 되어 있는데요. 그러면 지금 지정된 도서구분 명칭을 변경해 두고,
> 새로운 「도서구분」으로 생성할 수 있나요?

**가능합니다.** 다만 두 가지를 정해 주셔야 시작할 수 있습니다.

### 먼저 확인해 주실 점 — 기존 칸은 이름만 바꿉니다

지금 「도서구분」으로 표시되는 칸의 실제 값은 이렇습니다.


| 값   | 건수      |
| --- | ------- |
| 본사  | 1,863건  |
| 창고  | 1,458건  |
| 미지정 | 143건    |


이 칸은 **재고 계산이 본사분과 창고분을 가르는 기준**으로 쓰입니다. 도서별원장총괄의 본사도서 /
창고도서 선택도 이 값을 봅니다. 그래서 **값은 그대로 두고 화면에 보이는 이름만 바꿉니다.**
새 「도서구분」은 별도의 새 칸으로 만듭니다. 기존 재고 수치에는 영향이 없습니다.

### 정해 주실 것

1. **새 「도서구분」에 들어갈 값 목록** — 저서 · 번역서 · 원서 처럼 쓰실 값을 전부 알려 주세요.
   나중에 값을 더하는 건 언제든 가능하지만, 처음에 목록이 있어야 화면과 엑셀 양식을 맞춥니다.
2. **기존 본사/창고 칸의 새 이름** — 「보관처」 「재고구분」 「관리구분」 등이 후보입니다.

### 함께 여쭙습니다

- 새 도서구분을 **기존 도서 3,464건에도 채워야 하는지**, 아니면 앞으로 등록하는 책부터인지.
  전체에 채워야 한다면 일괄 입력용 엑셀 양식을 만들어 드리겠습니다.
- 새 도서구분으로 **조회나 집계**를 하실 것인지. 예를 들어 원서만 모아 보시려면 검색 조건과
  현황 화면에도 칸을 추가해야 합니다.

## 5. 「도서별원장총괄」 조회 속도

### 여쭙는 것

조건 없이 전체를 조회하면 결과가 나오기까지 10초 남짓 걸립니다. 도서 범위를 **필수**로 할지,
지금처럼 전체 조회를 허용할지 정해 주세요.

### 확인한 사실

이 화면은 재고 계산과 같은 3개 자료를 모두 읽고 도서별로 합칩니다. 그중 거래 원장이 교문사 기준
**1,535,793행**입니다. 조건 없이 전 기간을 조회하면 이 150만 행을 다 읽습니다.

레거시도 같은 계산을 하지만 사내망에서 도는 프로그램이라 체감이 달랐을 수 있습니다.

### 선택지

- **(가) 그대로 두기** — 느려도 전체를 한 번에 보실 수 있습니다.
- **(나) 도서 범위 필수** — 코드 구간을 반드시 넣게 합니다. 빠르지만 전체를 못 봅니다.
- **(다) 기본 기간을 좁히고 범위는 선택** — 열었을 때 기본 조회 기간을 최근 3개월로 두고,
  전체가 필요하면 기간을 늘리시면 됩니다.

**권고: (다).** 대부분의 조회는 최근 기간이라 체감이 빨라지고, 전체 조회 길은 막지 않습니다.
엑셀로 받으실 때는 지금처럼 전 기간이 그대로 나갑니다.
