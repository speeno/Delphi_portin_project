# 영업팀 UI 개선 요청사항 정리 (2026-08-13)

- **출처**: 영업팀 — 북이오웍스(도서물류 운영) 사용 의견, 사용자 경유 전달
- **접수일**: 2026-08-13
- **상태**: 전 항목 **미착수** (정리 단계 — 착수 지시 대기)
- **총평**: "가장 큰 문제점은 UI가 많이 불편합니다. 가독성이 좋지 않아요."

영업팀이 인식하는 화면 구조는 3분할이다: **좌측 메뉴 / 중앙 검색 결과값 /
우측 부수적인(보조) 값**. 아래 항목 번호는 이 구조 기준으로 매긴다.

---

## A. 레이아웃 · 색상

| # | 요청 | 원문 요지 | 비고 (현행/제약) | 상태 |
|---|------|-----------|------------------|------|
| A1 | 결과값 영역 흰색 유지 + **메뉴 영역에 색상** | "결과 값들은 흰색 바탕으로 하되 메뉴는 색상좀 넣어주고" | 색상 결정은 `docs/Design.md`(북이오웍스 디자인 SSOT) 토큰 체계 내에서. TSX 하드코딩 hex 금지 가드 존재 | 미착수 |
| A2 | **좌측 메뉴 바탕색 구분** | "좌측 메뉴는 바탕을 다른색" | A1과 동일 — 사이드바 배경 토큰 신설/변경 | 미착수 |
| A3 | **우측 보조 패널 너비 고정값** | "우측 부수적인 보조 결과 값은 너비를 일정하게 고정값으로 줄것" | 현재 화면마다 비율(fr) / 고정폭(w-80 등) 혼재. 공통 고정폭 규약 필요 — DataGrid 최소폭(DEC-146)과 별개 항목 | 미착수 |

## B. 메뉴 · 내비게이션

| # | 요청 | 원문 요지 | 비고 (현행/제약) | 상태 |
|---|------|-----------|------------------|------|
| B1 | 메뉴 설명을 **? 아이콘 hover 툴팁**으로 | "메뉴에 대한 설명은 ? 등으로 마우스온 시 보여줄 수 있도록 수정. 글자, 보조 메뉴가 너무 많아요" | 화면 상단 상시 노출 설명문(예: 도서별판매 부제)을 툴팁으로 이동하는 방향. 헤더 hint 는 `DataGridColumn.headerHint` 선례 있음 | 미착수 |
| B2 | **"가장 최근 본 메뉴" 상단 표시 삭제** | "가장 최근 본 메뉴 상단에 있을 필요 없음, 삭제 요망" | 워크스페이스 탭 스트립 영역(대시보드/거래처판매/도서별판매 … n/12 장) | 미착수 |
| B3 | **현재 위치 메뉴 강조** | "현재 위치 메뉴 표시 - 색상 변경 또는 바 형태든..." | 사이드바 활성 항목 하이라이트 강화 — A1/A2 색상 작업과 함께 처리 권장 | 미착수 |

## C. 상세 패널 배치

| # | 요청 | 원문 요지 | 비고 (현행/제약) | 상태 |
|---|------|-----------|------------------|------|
| C1 | 상세 내역을 우측이 아닌 **주 결과 하단(상하 배치)** 으로, **높이 축소 + 패널 내부 스크롤** | "상세 내역이 주 검색값 우측에 나타나는데 상하로 나오는 게 좋습니다. 높이를 줄여 스크롤바로 볼수 있게 변경 요망" | ⚠️ **당일 적용분과 상충**: 도서별판매·거래처판매 상세는 우측 sticky 패널로 정비됨(DEC-145/146, 사용자 요청). 단, 레거시(Sobo62 하단 DBGrid201)는 원래 **하단 배치**라 하단 복귀가 레거시 재현에는 더 가깝다. **채택 여부 결정 필요** | 결정 대기 |

## D. 미확인 항목 (원문 잘림)

- "**[도서별판매] 도서 검색시 …**" — 전달 메시지가 여기서 잘림. 이어지는 내용
  수신 후 본 문서에 추가할 것.

## 참고 — 같은 날 접수 즉시 처리 완료된 별도 요청 (본 문서 범위 외)

| 요청 | 처리 | DEC |
|------|------|-----|
| 도서별판매 합계 행 (전체 검색 결과 기준) | 서버 계산 totals + tfoot "합계(전체 결과)" | DEC-146 |
| 컬럼 과압축 시 숫자 표 밖 넘침 | DataGrid 공통 컬럼 최소폭 + 카드 가로 스크롤 | DEC-146 |
| 거래처판매 "수금액만 있고 전부 0" 오인 | 수금행에 최종 수금일 부여(정렬 정상 편입) | DEC-145 |
| 수량 컬럼 표기 "○○수" → "○○수량" | 화면 그리드 + XLSX 헤더 5종 | DEC-147 |

## 진행 방침 (제안)

1. **A·B(색상/메뉴)**: `docs/Design.md` 토큰 기준 시안을 먼저 제시 → 확정 후 일괄
   적용. 사이드바 배경(A2)·활성 강조(B3)·메뉴 색상(A1)은 한 묶음으로.
2. **A3(보조 패널 고정폭)**: 공통 규약(예: 고정 px + 최소 본문 폭 보장) 정의 후
   화면별 적용.
3. **B1·B2**: 독립 소규모 작업 — 우선 착수 가능.
4. **C1**: 사용자·영업팀 간 배치 선호가 갈리므로 **결정 먼저**(우측 sticky 유지
   vs 하단 복귀 vs 화면별 선택 옵션). 결정 후 DEC 기록.
