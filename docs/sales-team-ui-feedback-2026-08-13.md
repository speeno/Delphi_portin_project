# 영업팀 UI 개선 요청사항 정리 (2026-08-13)

- **출처**: 영업팀 — 북이오웍스(도서물류 운영) 사용 의견, 사용자 경유 전달
- **접수일**: 2026-08-13
- **상태**: 전 항목 **미착수** (정리 단계 — 착수 지시 대기)
- **총평**: "가장 큰 문제점은 UI가 많이 불편합니다. 가독성이 좋지 않아요."

영업팀이 인식하는 화면 구조는 3분할이다: **좌측 메뉴 / 중앙 검색 결과값 /
우측 부수적인(보조) 값**. 아래 항목 번호는 이 구조 기준으로 매긴다.

## A. 레이아웃 · 색상

| # | 요청 | 원문 요지 | 비고 (현행/제약) | 상태 |
|---|------|-----------|------------------|------|
| A1 | 결과값 영역 흰색 유지 + **메뉴 영역에 색상** | "결과 값들은 흰색 바탕으로 하되 메뉴는 색상좀 넣어주고" | **기적용(부분)**: 계정별 컬러 테마 10종+기본(`app/themes.css` `[data-theme]`, `ui_theme` 계정 선호 저장)이 이미 있어 메뉴 포함 전역 색조 변경 가능. 다만 "본문 흰색 유지 + 메뉴만 유색" 분리 배색은 미적용. 색상 결정은 `docs/Design.md`(SSOT) 토큰 체계 내에서 — TSX 하드코딩 hex 금지 가드 존재 | 미착수 |
| A2 | **좌측 메뉴 바탕색 구분** | "좌측 메뉴는 바탕을 다른색" | **기적용(약함)**: 사이드바는 전용 토큰(`--sidebar` #F5F5F7)으로 본문(#FFFFFF)과 이미 분리돼 있으나 대비가 미세해 체감 안 됨 → 토큰 값 조정 문제(구조 변경 불필요) | 미착수 |
| A3 | **우측 보조 패널 너비 고정값** | "우측 부수적인 보조 결과 값은 너비를 일정하게 고정값으로 줄것" | **기적용(혼재)**: 도서별판매 상세는 고정폭 `w-80`(DEC-138), 거래처판매 상세는 비율(fr, DEC-146) — 화면마다 다름. 공통 고정폭 규약으로 통일 필요. DataGrid 최소폭(DEC-146)과는 별개 항목 | 미착수 |

## B. 메뉴 · 내비게이션

| # | 요청 | 원문 요지 | 비고 (현행/제약) | 상태 |
|---|------|-----------|------------------|------|
| B1 | 메뉴 설명을 **? 아이콘 hover 툴팁**으로 | "메뉴에 대한 설명은 ? 등으로 마우스온 시 보여줄 수 있도록 수정. 글자, 보조 메뉴가 너무 많아요" | **기적용(부분)**: 사이드바 메뉴 항목은 이미 hover 툴팁 보유(캡션+품질/ETA, `sidebar.tsx` title + TooltipProvider 400ms). 그리드 헤더도 `headerHint` hover 지원. 미적용분 = 각 화면 상단 상시 노출 설명문(예: 도서별판매 부제)의 ? 툴팁 이동 | 미착수 |
| B2 | **"가장 최근 본 메뉴" 상단 표시 삭제** | "가장 최근 본 메뉴 상단에 있을 필요 없음, 삭제 요망" | ⚠️ **용도 확인 필요**: 상단 탭은 "최근 본 이력"이 아니라 **열린 폼 멀티탭**(`tab-bar.tsx` — 탭 전환/개별 닫기/모두 닫기, 레거시 MDI 창 등가). 삭제 시 여러 화면 동시 작업 워크플로가 사라짐 — 영업팀 의도(이력 표시로 오인?) 재확인 후 결정 | 확인 대기 |
| B3 | **현재 위치 메뉴 강조** | "현재 위치 메뉴 표시 - 색상 변경 또는 바 형태든..." | **기적용(약함)**: 활성 항목은 이미 배경 강조(`bg-sidebar-accent` Pale Lime + font-medium). 대비가 약해 체감 안 됨 → 좌측 바(bar) 표시 또는 강한 색 대비로 강화. A1/A2 색상 작업과 함께 처리 권장 | 미착수 |

## C. 상세 패널 배치

| # | 요청 | 원문 요지 | 비고 (현행/제약) | 상태 |
|---|------|-----------|------------------|------|
| C1 | 상세 내역을 우측이 아닌 **주 결과 하단(상하 배치)** 으로, **높이 축소 + 패널 내부 스크롤** | "상세 내역이 주 검색값 우측에 나타나는데 상하로 나오는 게 좋습니다. 높이를 줄여 스크롤바로 볼수 있게 변경 요망" | **기적용(절반)**: "높이 제한 + 내부 스크롤"은 이미 적용(거래처판매 상세 `max-h` + `overflow-y-auto`, DEC-145). 미적용분 = **상하(하단) 배치** — ⚠️ 당일 적용된 우측 sticky 패널(DEC-145/146, 사용자 요청)과 상충. 단, 레거시(Sobo62 하단 DBGrid201)는 원래 **하단 배치**라 하단 복귀가 레거시 재현에는 더 가깝다. **채택 여부 결정 필요** | 결정 대기 |

## D. 미확인 항목 (원문 잘림)

- "**[도서별판매] 도서 검색시 …**" — 전달 메시지가 여기서 잘림. 이어지는 내용
  수신 후 본 문서에 추가할 것.

## 진행 방침 (제안)

1. **A·B(색상/메뉴)**: `docs/Design.md` 토큰 기준 시안을 먼저 제시 → 확정 후 일괄
   적용. 사이드바 배경(A2)·활성 강조(B3)·메뉴 색상(A1)은 한 묶음으로.
2. **A3(보조 패널 고정폭)**: 공통 규약(예: 고정 px + 최소 본문 폭 보장) 정의 후
   화면별 적용.
3. **B1·B2**: 독립 소규모 작업 — 우선 착수 가능.
4. **C1**: 사용자·영업팀 간 배치 선호가 갈리므로 **결정 먼저**(우측 sticky 유지
   vs 하단 복귀 vs 화면별 선택 옵션). 결정 후 DEC 기록.
